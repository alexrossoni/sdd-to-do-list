# sdd-to-do-list

To-Do List simples desenvolvida com HTML, CSS e JavaScript vanilla, como exercício prático de **Sec-Driven Development (SDD)**.

## Estrutura do projeto

```
sdd-to-do-list/
├── index.html   # Estrutura da página
├── style.css    # Estilos visuais
├── app.js       # Lógica da aplicação
└── README.md
```

## Tecnologias

- HTML5
- CSS3
- JavaScript (ES6+)

## Como executar

Abra o arquivo `index.html` diretamente no navegador.
